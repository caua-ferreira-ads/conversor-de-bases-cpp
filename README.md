**Conversor de Bases Numéricas em C++**

Programa desenvolvido em C++ para realizar conversões entre diferentes sistemas de numeração.

**Funcionalidades**

- Conversão entre Decimal (base 10), Binário (base 2), Octal (base 8) e Hexadecimal (base 16).
- Seleção da base de entrada e saída.
- Validação de números e dígitos inválidos.
- Interface interativa por terminal.
- Suporte a números inteiros não negativos.

**Tecnologias utilizadas**

- Linguagem C++
- Biblioteca padrão do C++
- Programação estruturada

**Como executar**

1. Baixe o arquivo `main.cpp`.
2. Abra o arquivo em um ambiente de desenvolvimento C++.
3. Compile o programa.
4. Execute e escolha as bases numéricas desejadas.

**Exemplo de conversão**

```
Base de entrada: Binário
Base de saída: Hexadecimal
Número: 11111111

Resultado: FF
```
